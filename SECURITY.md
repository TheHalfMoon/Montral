# Security policy

Montral is an open-source, self-hostable project. There is no published production release or hosted Montral Cloud service at this time. The project does not claim a security certification or a guaranteed response time.

## Report a vulnerability privately

Use **Report a vulnerability** on the repository's GitHub **Security** tab. Private vulnerability reporting is enabled for this repository. Do not publish exploit details, credentials, personal information, or customer data in a public issue, discussion, or pull request.

Include the affected commit or version, the relevant feature or file, the conditions needed to reproduce the issue, its likely impact, and a safe proof of concept. Do not test against systems you do not own or have permission to assess. Do not use a suspected credential to check whether it is live; report its location and context privately so the owner or provider can verify it.

There is no published service-level agreement, bounty, supported-release window, or hosted-service incident contact. Until a release is published, reports should identify the exact source revision they affect.

## Scope

The source repository and its documented self-hosted behavior are in scope for reports. Montral Cloud and Enterprise BYOC are not production services. Do not treat their code, test-mode billing paths, or reference deployment configuration as evidence of a live hosted service.
