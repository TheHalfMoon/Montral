Cómo funciona

Un solo ciclo, del primer fallo a la normalidad.

Cada paso pasa al siguiente dentro del mismo producto, así que nada se copia entre herramientas mientras algo está caído.

  1. 01

    Observar

    Comprobaciones HTTP, TCP, DNS, ping, WebSocket, bases de datos, heartbeat y navegador con la frecuencia que decidas.

  2. 02

    Detectar

    Las sondas regionales se ponen de acuerdo antes de avisar, así que una ruta inestable no despierta a nadie.

  3. 03

    Responder

    Se abre un incidente y la alerta sigue tu calendario de guardias y tu política de escalado.

  4. 04

    Restaurar

    Publica novedades, resuelve y conserva la cronología. Tu página de estado se actualiza a la vez.

Una cronología que sirve de registro.

  • Reconocer, publicar novedades y resolver
  • Causa raíz y notas del postmortem
  • Historial de entregas de alertas en cada incidente

Desarrolladores

Lo que puedes pulsar, puedes automatizarlo.

Una API REST con claves con alcance, un servidor MCP para agentes de IA con consentimiento OAuth y un proveedor de Terraform que puedes compilar desde el código.

API REST

Las claves pueden limitarse a proyectos concretos. Se muestran una vez y se guardan cifradas con hash.

curl https://montral.invalid/api/monitors \
  -H "x-api-key: montral_..."
Referencia de la API

MCP para agentes de IA

Conecta Claude, Cursor o cualquier cliente MCP. Cada uno pide acceso de lectura o escritura mediante consentimiento OAuth.

claude mcp add --transport http \
  montral https://montral.invalid/api/mcp

Preguntas

¿Montral es realmente gratis?

Sí. Montral Community es código abierto con licencia MIT y no mide el uso. Solo pagas los servidores donde lo ejecutas.

¿Qué puede monitorizar?

Webs y API por HTTP y HTTPS, puertos TCP, registros DNS, ping, WebSocket, PostgreSQL, MySQL y Redis, heartbeats de tareas programadas, certificados TLS, caducidad de dominios y recorridos de navegador de varios pasos.

¿Cómo llegan las alertas a mi equipo?

Por los canales que conectes, como Slack, Microsoft Teams, PagerDuty, correo o un webhook, según tus calendarios de guardia y políticas de escalado. El correo y las notificaciones push necesitan un proveedor configurado en tu despliegue.

¿Pueden usarlo los agentes de IA?

Sí. Montral incluye un servidor MCP. Un agente se conecta con OAuth, pide acceso de lectura o escritura y trabaja dentro de los mismos límites de proyecto que su usuario.

¿Hay una versión alojada?

Todavía no. Hay una edición alojada en preparación, pero no está disponible públicamente ni tiene planes o precios publicados. Hoy la forma de usar Montral es autoalojarlo.
