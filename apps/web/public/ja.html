最初の失敗から復旧まで、ひとつのループで。

各ステップは同じ製品の中で次へ引き継がれるので、障害の最中にツール間で情報を写す必要はありません。

  1. 01

    観測

    HTTP、TCP、DNS、Ping、WebSocket、データベース、ハートビート、ブラウザのチェックを設定した間隔で実行します。

  2. 02

    検知

    複数リージョンのプローブが一致してから通知するので、一つの経路の不調で誰かを起こすことはありません。

  3. 03

    対応

    インシデントが起票され、アラートはオンコール表とエスカレーションポリシーに従って届きます。

  4. 04

    復旧

    更新を投稿し、解決し、タイムラインを残します。ステータスページも同時に更新されます。

監視

あらゆるチェックを、選んだリージョンから。

ポートが応答するかだけでなく、ステータスコード、キーワード、ヘッダーを検証できます。複数のリージョンプローブから実行し、結果が一致したときだけ通知します。

  • モニターごとの間隔とタイムアウト
  • 一時停止、再開、今すぐチェック

オンコール

ローテーションのレイヤーと臨時交代を備えたスケジュール、誰も確認しないときに段階を上げるエスカレーションポリシー、個人のカレンダーで購読できるフィード。

  • 交代や休暇のための一時的な代理

開発者

クリックできることは、自動化できる。

スコープ付きキーの REST API、OAuth で同意する AI エージェント向け MCP サーバー、ソースからビルドできる Terraform プロバイダー。

REST API

キーは特定のプロジェクトに限定できます。表示は一度だけで、その後はハッシュとして保存されます。

curl https://montral.invalid/api/monitors \
  -H "x-api-key: montral_..."
API リファレンス

AI エージェント向け MCP

Claude、Cursor など任意の MCP クライアントを接続できます。各クライアントは OAuth で読み取りまたは書き込みの許可を求めます。

claude mcp add --transport http \
  montral https://montral.invalid/api/mcp

数コマンドで動きます。

$ cd Montral
$ cp .env.docker.example .env   # set POSTGRES_PASSWORD
$ docker compose up -d --build

よくある質問

Montral は本当に無料ですか？

はい。Montral Community は MIT ライセンスのオープンソースで、利用量の計測はありません。費用は動かすサーバーの分だけです。

何を監視できますか？

HTTP / HTTPS のウェブサイトと API、TCP ポート、DNS レコード、Ping、WebSocket、PostgreSQL・MySQL・Redis、定期ジョブのハートビート、TLS 証明書、ドメインの有効期限、複数ステップのブラウザジャーニーです。

アラートはどうチームに届きますか？

Slack、Microsoft Teams、PagerDuty、メール、Webhook など接続したチャネルに、オンコール表とエスカレーションポリシーに従って届きます。メールとプッシュにはデプロイ側でプロバイダーの設定が必要です。

AI エージェントから使えますか？

はい。Montral は MCP サーバーを内蔵しています。エージェントは OAuth で接続して読み取りまたは書き込みの許可を求め、ユーザーと同じプロジェクトの範囲内で動作します。

ホスト版はありますか？

まだありません。ホスト版は準備中ですが一般には提供されておらず、プランや価格も公開していません。現在はセルフホストでご利用ください。
