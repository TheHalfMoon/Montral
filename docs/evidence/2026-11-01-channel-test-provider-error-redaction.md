# Channel test HTTP + audit diagnostic privacy — Mac / PostgreSQL regression

**Date:** 2026-11-01 Asia/Riyadh. **Scope:** private repository, synthetic SMTP-like transport and fresh disposable PostgreSQL; no real email, production provider, paid service or deployment.

## Verified issue before repair

`POST /api/channels/:id/test` caught any outgoing delivery exception but copied its raw `.message` both to the HTTP 502 JSON payload and the persisted `alert_delivery.error/status_message`. Although the scheduled alert fanout already uses category-only diagnostics, this user-triggered channel test was an inconsistent route. An SMTP binding, push service or external webhook transport can include contact details or credentials in an exception message. A real PostgreSQL end-to-end test injected a synthetic provider rejection containing a unique private marker. **RED:** the 502 body contained that marker instead of the expected generic `notification delivery failed` response; the original handler also passed the same unredacted message to the persistent audit helper. No actual provider was contacted.

## Narrow correction

Expose the existing `safeDeliveryReason` classifier from `alerts.ts` for reuse by the channel-test route rather than copying untrusted provider text. Safe output categories retain the explicit unconfigured-provider condition (`Email provider is not configured`) and bounded HTTP numeric codes; otherwise all raw provider text becomes `notification delivery failed`. The 502 status and failure audit remain intact. If the audit itself fails, log a constant failure diagnostic and return 502 rather than letting an unrelated audit outage leak internal errors or change the user's delivery result. API documentation now describes the redacted delivery category.

**GREEN:** both real-PostgreSQL E2E cases pass: (1) unconfigured email stays a failed send with the exact established operator-visible explanation, and (2) a configured synthetic sender throwing an arbitrary private diagnostic yields a generic 502 and a failed delivery audit that contains no private marker. No quotas, provider retry semantics, network permissions or production sending features were changed.
