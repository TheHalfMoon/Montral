# Authorize notification destination creation

The API explicitly reserved changes to notification destinations for workspace owners and admins, but channel creation had only the surrounding membership guard. An ordinary member session or API key could create enabled external destinations, including project-scoped ones. Organization-owned channels remain configured independently of their creator's membership. This bypassed the destination-selection role boundary; it did not reveal existing provider credentials or another tenant's data. Members already have incident read access and operational monitor permissions, and autoEnable affects only new/imported monitors.

A real Hono/PostgreSQL regression created an owner-bound key and then demoted current membership. Session workspace-channel creation and key project-channel creation both returned 201, failing the expected 403 responses. Adding the existing requireManager before the POST validator closes the missing check for all types and scopes. Existing member rename/toggle and approved-channel selection remain unchanged. Automatic push provisioning already independently restricts channel creation to owner/admin memberships.

The new case verifies both denied credential paths, absence of new stored channels, member rename/toggle success, continued destination-replacement refusal, admin-key creation and owner-session creation. Seven channel, secret, delivery-scope and OAuth suites passed 60/60 using a disposable localhost database. API TypeScript, Node build, source and diff checks passed. Fresh independent prepatch investigation and one fresh postpatch bypass review completed; no actionable remaining issue found. Reviewer did not rerun the active database tests. Public English API documentation now states the creation restriction.

Hosted final-head checks and merge remain pending. This change does not remove destinations previously created by members; managers should review existing destinations when upgrading. No provider was contacted and no production notification, deployment or publication occurred. The broader managed security audit remains partial.
